先读这一条：什么是"证据分级"THE CORE IDEA

大部分天文科普只告诉你"结论是什么"。本作品多做一步：告诉你这条结论靠什么支持、在什么范围内成立。我们把支持方式分成三类，每条知识都会在证据卡的「证据类型」字段里标明属于哪一类。这是本作品与普通天文科普 App 最主要的区别。

LEVEL A观测证据

由望远镜观测数据直接或比较直接支持的说法：看得见、测得着，不同团队可以重复观测与核对。看到这个标签，你可以追问："天文学家是怎么看到的？"

LEVEL B理论模型

依据已知物理规律推演出来的过程描述，而这个过程本身很难被从头看到尾。看到这个标签，你可以追问："这一步是被看到的，还是被推出来的？"

LEVEL C仍在研究

学界尚无定论的开放问题，即使研究对象本身已经被观测到。看到这个标签，你应当知道：这里没有标准答案，教科书也可能改写。

例子一：同样写在科普里，"可信"的来源可能是两种不同的东西

  1. 「恒星一生的大部分时间处于主序阶段，核心稳定地把氢聚变为氦」——标为观测证据。不同质量恒星在赫罗图上的分布、它们的光谱与光度特征，都是可反复核对的观测事实。
  2. 「原恒星靠引力收缩聚集物质、中心升温」——标为理论模型。恒星形成过程历时漫长且常被尘埃遮挡，无法端到端地观看；它主要由物理定律推演得出，用来解释我们看到的现象。

两者都值得相信，但相信的理由不同：一个靠观测，一个靠推演。分清之后你就知道，哪一种更可能在将来被新的观测修正。

例子二：同一个天体，可以同时拥有观测证据和未解之谜——中子星

中子星本身的存在是被观测支持的（脉冲星信号已被长期记录），但"中子星内部在极端密度下处于什么物质状态"至今仍在研究。所以它的证据类型字段写的是「观测证据 · 内部结构仍在研究」——而不是笼统地说"科学家已经搞清楚了"。把一个天体的"存在"和它的"内部细节"混为一谈，是科普里最常见的跳跃。

为什么科普要区分它们：① 防止把阶段性理解讲成定论；② 让读者知道自己可以在哪里质疑、去查哪一类来源；③ 帮助建立正确的科学观——科学结论的强度是分级的，会随新证据更新。本页的三类标签由团队依据 NASA 科普页面的表述人工标注，内容尚待天文或科学教育人员专业审阅（见作品说明「验证与测试自查」）。

作品说明

1 · 作品简介与目标用户

《星问》是一个面向中学生与天文初学者的恒星演化导览工具。使用者点选星图上的天体、或输入一个问题，系统会给出一条结论，并同时说明这条结论的适用范围、证据类型、来源与复核状态。

设计目标不是"回答更多问题"，而是帮助初学者建立一种习惯：看到结论时，先追问它靠什么支持、在什么范围内成立。目标使用场景为课堂自学、天文社团活动与科普展览中的自助查询。

2 · 适用学段与教学目标（教学设计）

适用学段与受众：

  • 初中科学（7–9 年级）：作为"地球与宇宙"主题的课后探究材料，重点放在"用证据说话"，不涉及计算。
  • 高中地理／天文模块：作为恒星演化单元的预习或复习支架，重点放在适用范围与证据分级的辨析。
  • 天文社团与科技馆科普场景：作为自助查询终端或社团活动任务单，学习者可按「引导式学习路径」独立完成一轮探究。

内容目标：围绕"恒星演化的顺序与结局"一条主线，收录 8 条知识；每条只包含能被公开来源支持的表述，不以覆盖面广度为取舍。

教学目标与对应交互环节（每条目标在作品中都有落点）：

  1. 目标 1 · 能区分观测证据、理论模型与仍在研究三种支持方式。落点：页面顶部「什么是证据分级」说明区的两个对照例子，以及引导式学习路径第 3 步（给 3 条结论分级，答错可重做）。
  2. 目标 2 · 能说出一条结论的适用范围。落点：每张证据卡中的「适用范围」字段，以及引导式学习路径第 2 步（逐条勾选"已读适用范围"，至少 3 条）。
  3. 目标 3 · 遇到未收录的问题会主动查证，而不是接受一个编造的答案。落点：提问未命中时的拒答提示与「建议查证方向」清单，以及引导式学习路径第 5 步的开放题作答。

达成标记怎么来的：三条目标在学习档案中输出"达成／进行中／未开始"，依据依次为：分级判题正确题数、已标记阅读的适用范围条数、本机是否出现过范围外提问与是否提交开放题。本机自评这些标记由本机交互自动采集，只反映一次使用过程，不等同于经过验证的教学效果测量（课堂前测与后测尚未开展，见第 8 节）。

3 · 创新点（三条）

  1. 证据链可视化的知识卡片：每条结论被拆成"简明结论 / 适用范围 / 证据类型 / 来源名称与链接 / 复核状态"五个字段，证据不再是脚注，而是与结论同等权重的界面主元素。常见天文科普 App 通常只给结论与配图，读者无法判断结论的适用边界。
  2. 来源可追溯：每条结论固定绑定一个可点击的公开来源（NASA 官方科普页面），并有独立的"这条结论靠什么支持"引导语；读者可一键跳转原始页面自行核对，而不是停留在二手转述。
  3. 范围外明确拒答：系统只做本地关键词与同义词表匹配。未命中时显示"证据不足，本条目未收录"，并给出建议查证方向（应查阅哪一类公开来源），不生成任何事实性答案。这与"用生成式模型补全一切"的常见做法相反，把"不知道"作为一种可交付的输出。

4 · 证据分级与引用规范

分级标准：页面顶部「什么是证据分级」说明区给出具体例子，此处给出判定口径——

  • 观测证据：该表述可由望远镜观测数据直接或较直接支持；
  • 理论模型：该表述是由已知物理规律推演出的过程描述，难以端到端观测；
  • 仍在研究：学界尚无定论；若同一条目同时含两种成分，则在字段中并列写出（如中子星条目）。

三类标签由团队依据 NASA 科普页面的表述人工标注，尚待天文或科学教育人员专业审阅。

引用格式：每条知识在证据卡中提供可复制的引用行，格式为「来源名称《页面标题》，链接（访问日期：由引用者填写）」。访问日期留空，由引用者按实际访问日期补齐，避免出现在未访问的情况下冒用访问日期。

收录筛选标准（四条，缺一不收）：

  • ① 必须有公开可访问的来源页面（本页仅使用 NASA 官方科普页面），无公开来源的条目不收录；
  • ② 必须是面向公众的成熟表述，不收录存在争议的具体数值与研究前沿；
  • ③ 必须写得出适用范围——写不出适用范围的表述不收录；
  • ④ 只收恒星演化主线上的内容；黑洞、宇宙学参数等超出范围的话题一律明确拒答并给出查证方向，不临时补写答案。

5 · 引导式学习路径、学习凭证与教师视图

引导式学习路径「从星云到恒星遗迹」：5 步探究任务——① 沿演化链看 5 个节点 → ② 逐条阅读「适用范围」（至少 3 条）→ ③ 给 3 条结论做证据分级（可重试）→ ④ 完成形成性测验中至少 6 题 → ⑤ 回答一道开放题（不少于 30 字；系统不判分，只记录字数与是否提交）。每步都有进度条、"已完成"标记与首次完成时间；路径不替代自由检索，随时可以回到星图随意点。

学习凭证：5 步全部完成后自动生成，含使用者自填的学习者标识、各步完成时间与三条教学目标的达成标记，可导出 star-pathway-certificate.json；同样内容也会写入学习档案。凭证由本机生成，不代表任何外部机构的认定。

教师视图：可粘贴或上传多条学习档案 JSON，在本机汇总参与人数、测验平均正确率、高频错题、高频未命中问题与教学目标达成人数，并导出 star-class-summary.csv（带 BOM，Excel 可直接打开）。全部解析与统计在浏览器本地完成，不上传服务器、不发起任何网络请求；导入的数据只存于内存，清空或刷新即消失。用户粘贴的 JSON 均经过 try/catch 与字段校验，失败时给出具体原因而不是静默忽略。

6 · 技术路线

  • 纯 HTML + CSS + 原生 JavaScript 单文件实现，无构建步骤、无外部依赖、无网络请求。
  • 检索方式为本地规则检索：关键词表 + 手写同义词表按最长匹配命中，返回内置知识卡片。
  • 不调用任何生成式模型或在线模型 API，所有回答均来自内置条目，结果可复现、可审计。
  • 知识卡片以数据结构内置于页面脚本中，星图与节点为代码绘制（CSS 渐变与定位），不使用位图素材。
  • 学习档案与学习凭证在浏览器本地生成并以 JSON 文件下载；班级汇总 CSV 同样在本地生成，数据不出本机。
  • 引导式学习路径与教师视图均为同一文件内的原生脚本，无任何后端、无 localStorage 持久化；刷新页面即从空白状态开始。

7 · 操作与运行说明

  1. 双击或直接用浏览器打开 star.html 即可运行，无需安装环境、无需联网。
  2. 左侧星图含 8 个天体节点，点击或使用 Tab + Enter 选择，右侧同步显示证据卡。
  3. 在输入框中提问（如"太阳会变成黑洞吗""红巨星""脉冲星"），系统做本地匹配；命中则展示条目与证据，未命中则给出拒答提示与查证方向。
  4. 完成形成性测验（3 组 × 3 题）后即时查看解析，并可通过"查看证据卡"回链到对应条目。
  5. 页面顶部的「什么是证据分级」建议先看：它解释后面每张证据卡里的"证据类型"字段。
  6. 点击"导出学习档案"可下载 star-learning-record.json，含查看过的节点、提问记录、测验结果，以及学习路径完成情况与教学目标达成标记。
  7. 「引导式学习路径」为一条 5 步任务，逐步完成后自动生成可导出的学习凭证 star-pathway-certificate.json。
  8. 「教师视图」粘贴或上传多条学习档案 JSON，本机汇总后可导出 star-class-summary.csv；刷新页面即清空全部本机数据。
  9. 右上角"作品说明"打开本抽屉，按 Esc 或点击遮罩关闭。
